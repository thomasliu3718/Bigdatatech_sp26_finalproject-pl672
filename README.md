# NYC Crime Data Analysis Package

## Purpose
This project provides a Python package for analyzing and visualizing crime trends in New York using real-world datasets.

## Dataset
The dataset is obtained from NYC Open Data:
https://data.ny.gov/

It contains yearly crime statistics across counties in New York.
